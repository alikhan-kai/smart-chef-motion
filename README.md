## Зачем мы это сделали

Руки в муке, на плите кипит соус, а телефон просит пролистать рецепт. Знакомая ситуация? Smart Chef помогает пройти весь путь от «что приготовить?» до готового блюда, сохраняя руки свободными.

Напишите, какие продукты есть дома, получите пошаговый рецепт и уточните его в чате. На кухне покажите 👍, чтобы перейти дальше, или попросите Алису запустить таймер. Для управления жестами достаточно браузера и веб-камеры — распознавание работает на устройстве.

## Попробуйте сами

Проект **уже задеплоен**: [smartchef.ailab-sdu.com](https://smartchef.ailab-sdu.com/). Для знакомства не нужно устанавливать Docker или запускать бэкенд.

Для первого знакомства используйте ноутбук с веб-камерой и разрешите доступ к ней. Держите кисть целиком в кадре при хорошем освещении. Между командами опускайте руку: пауза распознавания составляет 1,5 секунды, длительно удерживаемый жест может сработать повторно.

1. Откройте сайт и зарегистрируйтесь или войдите.
2. Напишите: **«У меня есть курица и макароны. Хочу ужин за 30 минут»**.
3. Уточните рецепт в чате: **«Замени сливки»** или **«Сделай на две порции»**.
4. Перейдите к готовке, разрешите доступ к камере и покажите **👍** — откроется следующий шаг.
5. На шаге с таймером покажите **✌️**, чтобы запустить отсчёт, и **✋**, чтобы остановить его.
6. Покажите **👎**, чтобы вернуться назад, затем пройдите шаги вперёд. **👍 на последнем шаге завершает рецепт**: книга закрывается, звучит сигнал успеха и появляется конфетти. За каждый впервые пройденный шаг в текущей сессии начисляется 20 XP.

Навык Алисы **отправлен на модерацию**. Голосовой сценарий — дополнительная интеграция; основной сценарий с камерой можно пройти без Станции и без ожидания публикации навыка.

## Как мы решаем кейс Motion

Наш законченный сценарий — **пройти рецепт от первого шага до завершения, управляя готовкой жестами**. Вход, выбор рецепта и разрешение камеры выполняются обычным интерфейсом; после входа в режим готовки шаги и таймер управляются без клавиатуры и мыши.

| Требование кейса | Реализация Smart Chef |
|---|---|
| Распознавание в реальном времени в браузере | MediaPipe обрабатывает кадры веб-камеры в режиме VIDEO |
| Не менее трёх разных движений | Четыре жеста с отдельными действиями: вперёд, назад, запуск и остановка таймера |
| Понятная обратная связь | Скелет кисти поверх камеры, название распознанного жеста и зелёная подсветка принятой команды |
| Законченный сценарий | Последний жест завершает рецепт: анимация закрытия книги, звук, конфетти и накопленный XP |
| Без установки приложения | Работающая HTTPS-версия в браузере |
| Обязательный режим «ошибка» | Собственные проверки положения пальцев и конкретные подсказки для Лайка и Peace — подробнее ниже |

Бонусы по кейсу: собственные геометрические правила поверх модели, прогресс пользователя (XP и уровни), звуки и визуальные эффекты. Интерфейс имеет адаптивную вёрстку; качество распознавания на конкретном телефоне зависит от камеры и браузера.

## Управление жестами

| Жест | Действие |
|---|---|
| 👍 Лайк | Следующий шаг |
| 👎 Дизлайк | Предыдущий шаг |
| ✌️ Peace | Запустить таймер |
| ✋ Открытая ладонь | Остановить таймер |

MediaPipe распознаёт кисть прямо в браузере. Мы дополнительно проверяем положение пальцев: например, для «Лайка» остальные пальцы должны быть согнуты. Если жест выполнен неточно, приложение показывает конкретную подсказку. Пауза между срабатываниями защищает от случайного перелистывания нескольких шагов.

### Режим «ошибка»: что исправить в жесте

Готовая модель определяет класс жеста, а наша логика в [js/ml.js](js/ml.js) проверяет координаты кисти перед выполнением действия:

| Жест | Собственная проверка | Конкретная подсказка |
|---|---|---|
| 👍 Лайк | Кончики среднего, безымянного пальцев и мизинца должны быть ближе к запястью, чем основания этих пальцев | «Сожмите остальные пальцы в кулак, чтобы распознать жест “Лайк”» |
| ✌️ Peace | Расстояние между кончиками указательного и среднего пальцев должно быть не меньше 0,045 в нормализованных координатах кадра | «Пальцы слишком близко! Раздвиньте указательный и средний пальцы шире, чтобы распознать жест “Peace”» |

При провале проверки команда не выполняется, появляется оранжевая подсказка. После исправления жеста приложение выполняет действие и показывает зелёное подтверждение. Так пользователь видит связь между движением, ошибкой и исправлением.

**Граница MVP:** эти две проверки включаются, когда модель уже распознала соответствующий класс. Для `None` и кулака пока выводится общая подсказка; отдельной диагностики неточного Дизлайка и Ладони нет. На демонстрации важно показать именно конкретную коррекцию положения пальцев, а не только сообщение «жест непонятный».

Проверить твист можно на шаге с таймером: покажите Peace и постепенно сблизьте пальцы, сохраняя жест узнаваемым. Когда сработает проверка расстояния, появится подсказка; разведите пальцы и повторите команду. Если модель перестала узнавать Peace, верните кисть в исходное положение. Аналогично для Лайка проверяется сгибание остальных пальцев.

## Алиса на вашей кухне

Мы добавили интеграцию с **Яндекс Станцией**: голосовая команда управляет таймером текущего рецепта в Smart Chef. Это дополняет жесты — можно следить за блюдом и попросить запустить отсчёт, не подходя к экрану.

### Как подключить

**Статус: навык отправлен на модерацию, публичная доступность пока не подтверждена.** Инструкция ниже предназначена для аккаунтов с доступом к тестированию или для использования после публикации. Название «Умный шеф» используется в интерфейсе — при настройке собственного навыка используйте его фактическое имя активации.

1. Откройте рецепт на сайте и перейдите в режим готовки.
2. Нажмите **«Подключить Алису»** — появится шестизначный код, действующий 10 минут.
3. Скажите: **«Алиса, запусти навык Умный шеф»**.
4. Назовите код с экрана: **«Код 123456»** — подставьте свои цифры.
5. Дождитесь статуса **«Алиса подключена»** и произнесите команду внутри навыка.

| Команда | Что произойдёт |
|---|---|
| «Запусти таймер» | Запустится таймер текущего шага |
| «Поставь таймер на 5 минут» | Запустится отсчёт с указанной длительностью, если она подходит текущему шагу |
| «Останови таймер» | Отсчёт остановится |

Алиса учитывает рецепт: если шаг требует 20 минут, команда на 10 минут будет отклонена с пояснением. Для шага без заданного времени можно установить свой таймер.

Таймер и сигнал работают **в открытой вкладке Smart Chef**, поэтому браузер должен оставаться открыт и подключён к интернету. Для другой Станции есть действие **«Переподключить другую Станцию»**. После перезапуска бэкенда потребуется новый код.

Создание навыка, настройка webhook и технические детали: [гайд по интеграции Алисы](docs/yandex_alice_integration.md).

## Как это устроено

![Архитектура Smart Chef](docs/architecture.svg)

Браузер отвечает за камеру, жесты и пошаговую готовку. FastAPI принимает запросы чата, а слой LLM получает структурированный рецепт через OpenAI Responses API. Supabase хранит аккаунты, историю и журналы при настроенном постоянном хранении. Навык Алисы отправляет команды на бэкенд, откуда их получает открытая страница готовки.

| Часть | Технологии |
|---|---|
| Интерфейс | Vanilla JS, HTML, Tailwind, анимация книги, Web Audio |
| Распознавание жестов | MediaPipe Tasks Vision |
| API и валидация | Python 3.12+, FastAPI, Pydantic |
| Генерация и уточнение рецептов | OpenAI SDK, Responses API, строгие JSON-схемы |
| Хранение | Supabase / PostgreSQL |
| Голосовое управление | Яндекс Диалоги, webhook, привязка по коду |
| Развёртывание | Docker Compose, Nginx, HTTPS через Cloudflare Tunnel |
| Проверки | pytest, ruff, mypy, smoke-проверка деплоя |

Основной код: `backend/`, `llm/`, `js/`. Вложенный `recipe-ai-backend/` — ранний эксперимент с LangChain; текущий Docker-деплой использует **корневой бэкенд**.

### Собственная логика и готовые инструменты

Мы используем готовую модель жестов MediaPipe и API генерации текста. Собственный вклад — проверки геометрии пальцев и корректирующие подсказки, привязка жестов к шагам рецепта, управление камерой и таймером, чат с версиями рецепта, журналы и мост между Алисой и браузером. Обучение собственной нейросети не заявляем.

Код для проверки: [распознавание и режим ошибки](js/ml.js), [шаги, таймер и завершение](js/ui.js), [логика чата](backend/services/chat_service.py), [интеграция Алисы](backend/services/yandex_alice_service.py). История разработки доступна в [коммитах репозитория](https://github.com/alikhan-kai/smart-chef-motion/commits/main/).

## Быстрый запуск

Для своего запуска нужны Git, Docker с Compose, ключ OpenAI и доступ в интернет:

```bash
git clone https://github.com/alikhan-kai/smart-chef-motion.git
cd smart-chef-motion
test -f .env || cp .env.example .env
# Заполните OPENAI_API_KEY и OPENAI_MODEL в .env.
docker compose up --build -d --wait
```

Если репозиторий уже скачан, выполняйте команды начиная с подготовки `.env` из его корня.

Интерфейс: **http://localhost:8080** · API: **http://localhost:8000/docs**

Для постоянного хранения настройте Supabase по гайду. Без обеих серверных настроек `SUPABASE_URL` и `SUPABASE_SERVICE_KEY` журналы и книга рецептов на бэкенде живут в памяти. Браузерное подключение в `js/config.js` настраивается отдельно.

Проверка Docker-стека без генерации рецептов и записи данных:

```bash
python3 scripts/smoke_docker.py
```

## Что дальше

За хакатон мы собрали сквозной сценарий: запрос → уточнение → готовка жестами, с дополнительным голосовым управлением таймером. Следующие шаги — пройти модерацию навыка Алисы, расширить диагностику неточных жестов, сохранять чаты и привязки между перезапусками, подготовить полноценную аутентификацию для публичного сервиса.

Сейчас это хакатонный MVP: чаты и привязки Алисы хранятся в памяти одного процесса. Подробные ограничения и особенности настройки описаны в гайдах, чтобы демо было легко воспроизвести.
